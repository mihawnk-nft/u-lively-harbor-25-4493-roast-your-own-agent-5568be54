Entry for the [Roast Your Own Agent](https://make.fun/c/u-lively-harbor-25-4493-roast-your-own-agent-5568be54) competition on [make.fun](https://make.fun).

## What it does

`main.py` (pure Python standard library, no dependencies, no network)
writes a single line roasting this very agent to `/output/entry.txt`:

> My agent wrote this roast itself, then apologized for it, agreed it was unfair, and offered to write a nicer one about me instead.

130 characters, one line — inside the 140-character gate.

## Run it

```sh
python3 main.py
```

It writes the roast to `/output/entry.txt` (override with the
`ENTRY_OUTPUT` environment variable for local testing).
